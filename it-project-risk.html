Core Delivery Model

Build Test Launch Validate

The Build Test Launch Validate lifecycle is retained as the central organising model, with controls embedded into the work rather than added after release.

Stage 01

Build

Purpose, scope, ownership and design

Illustrative Controls

  • ✓ Use-case definition
  • ✓ Accountable owner
  • ✓ Data and access boundaries
  • ✓ Supplier due diligence
  • ✓ Control requirements
  • ✓ Decision log
Stage 02

Test

Evidence before release

Illustrative Controls

  • ✓ Test plan
  • ✓ Functional and risk scenarios
  • ✓ Security and privacy checks
  • ✓ Human review
  • ✓ Defect and exception handling
  • ✓ Release criteria
Stage 03

Launch

Controlled transition into use

Illustrative Controls

  • ✓ Approval record
  • ✓ Change and training plan
  • ✓ Access provisioning
  • ✓ Operating procedures
  • ✓ Incident path
  • ✓ Rollback or contingency plan
Stage 04

Validate

Confirm performance and ongoing control

Illustrative Controls

  • ✓ Outcome measures
  • ✓ Control evidence
  • ✓ Incident and exception review
  • ✓ User feedback
  • ✓ Residual risk review
  • ✓ Improvement actions
